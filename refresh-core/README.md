# 刷新核心（refresh-core）

插件内置的 TypeScript 能力，第一批只做「新刷新机制」里那些**纯逻辑**：闸要用的节拍与额度、
一份请求属于哪一类、一次裁决的结论长什么样、工具调用前的花费预估长什么样。
形态照仓库里既有的 `update-core/` 与 `label-color-core/`：源码放在仓库根这个独立目录里，
编译产物逐文件落进 `src/shared/refresh/` 并提交进 git，**不发 npm 包**、不进 pnpm workspace、
不建 `packages/<名字>/`（决策记录见 `docs/adr/20260913-builtin-ts-shape.md`）。

新机制的设计定稿在 `docs/architecture/refresh-budget-architecture.html`，地图票是 `#704`。

## 里面有什么

- `src/ports.ts`：插口形状——请求类别（用户动作 / AI 工具 / 生命周期 / 后台）、档位（绿 / 黄 / 红）、
  裁决结果（放行 / 降级 / 推迟，带一句原因）、花费预估的返回形状（点数、请求数、两组硬顶是否够用、
  分片建议），最后一行是模块标识 `PORTS_SOURCE`。这里**不放数字**（数字全在 `budget.ts`），
  也**不放裁决规则与原因代号表**（归后面的 `policy.ts`）。核心只管做决定，插口由核心定，
  跑腿的活全在外面。
- `src/budget.ts`：全部节拍与额度的**唯一真源**——常量与由它们算出来的算式两部分。
  常量包括探测 5 秒、对账 10 分钟、环境预检寿命 10 分钟（失败立刻重试一次）、检查链退避序列
  8 秒 → 30 秒 → 2 分钟 → 5 分钟、全绿缓存 30 分钟、插件每小时最多用掉剩余额度的 35%
  （绝对上限 1750）、读 ≤70%（1225）、写保底 30%（525）、三档降级的两条阈值、活跃集合上限 2、
  视野失效 90 秒、行级补行的合并窗口 10 秒、`MAX_PAGES = 10`，以及 AI 工具那一档的两组硬顶
  （单次 ≤600 点且 ≤400 次出站请求；每小时 ≤2000 点且 ≤1500 次请求；一次调用最多建 60 张子票，
  超过就分片，每片 ≤60 张）。算式包括每小时可用额度、读的份额、写的保底、用掉多少、档位判定、
  分片建议、两组硬顶判定。**别的票一律 import 这里的名字，不许再写一遍字面量**。
- `build.mjs`：编译脚本。esbuild 只转译不打包，一对一生成 `src/shared/refresh/` 下的同名 JS；
  另跑 `tsc --noEmit` 只做类型检查。导出 `transpileUnit`、`runTypeCheck`、`buildAll` 三个函数，
  `scripts/build.mjs` 在派生步骤之前按顺序各调一次。
- `tsconfig.json`：类型检查配置（严格模式，不产出）。

本票（`#720`）只建上面两个源码文件，因为这一票的边界就是「把这棵核心建起来、接进构建、配上门禁」。
票面里写的另外四个文件——`policy.ts`（裁决纯函数）、`delta.ts`（行级差分的合并规则、水印推进、
世代号比较）、`write-detect.ts`（写事件判定表）、`tool-cost.ts`（花费预估与分片建议）——由后面各自的票
落地，它们要的数字与形状这里已经备好。

## 三条结构纪律

1. **先写形状再写实现**：先定 `ports.ts` 里的形状，再写实现文件。本票已经按这个顺序落地。
2. **纯逻辑不碰磁盘与网络，读写一律走注入进来的适配器**：核心里没有读文件、起进程、联网的代码；
   第一、二批文件里一行都没有，将来也不该有——取数与落盘留在 JavaScript 那一侧。
3. **按能力分目录、按能力命名文件**：一个文件一件事，不设「基础层 / 平台层 / 工作台层」。
   核心长大之后仍是加文件、不是加层。

## 哪些东西不写进 TypeScript（照 ADR §2.7，长期形态）

- **取数与落盘**：tracker 契约层、三个后端房间、往工作区写文件的原子写与单写者队列、宿主取数与落盘。
- **日志埋点**：写日志的代码留在 JavaScript 那一侧（核心只提供要记的数字与结论）。
- **视图渲染**：面板本体、列表行、弹窗，全部留在 `src/client/` 下。
- **样式、图标、主题变量**：留在现有 JS 里。
- **拼接进闭包的叶子模块与构建胶水**：`scripts/build.mjs`、`scripts/derive-*.mjs`、`src/client/index.js`
  里的拼接标记，留在 JS。
- **词条与文案**：留在 `src/client/kernel/locale*.js` 的词表里，中英两份都要加。

理由：类型真正值钱的地方是「错了不会崩、只会静默算错」的纯逻辑（额度算式、裁决规则、写事件判定表、
行级差分、世代号比较），而 I/O 那一层要挡的是平台差异，类型管不到跨进程与跨 HTTP 的真实形状。
另外，TypeScript 源码放进 `src/host/**` 或 `src/shared/**` 会真出事：构建对这两棵树是整树递归复制，
`.ts` 会被当死源码一路发到用户机器上。

## 常用命令

- `node scripts/build.mjs`：日常只用这一条。它先跑类型检查与转译本目录，再拼客户端、复制宿主。
- `node refresh-core/build.mjs`：只做本目录的类型检查与转译。单独跑完之后要再跑一次
  `node scripts/build.mjs`，否则 `tests/verify-kernel.js` 之类看「产物比源码旧」的门禁会红
  （本票的产物还没有进那份 `SOURCES` 列表，等宿主侧接线那票再接）。
- `node tests/verify-refresh-freshness.js`：改了 TypeScript 没重新生成就变红。

## deck 侧落点

- 产物两个：`src/shared/refresh/ports.js`（空壳，只剩一行模块标识，现在没有运行时代码引用它，
  门禁读它一次）与 `budget.js`。两个都提交进 git。
- 宿主侧与界面侧将来都用普通相对 import 取用，例如
  `import { PROBE_INTERVAL_MS } from '../shared/refresh/budget.js'`。
- 本票**没有**把任何产物拼进客户端闭包，所以 `SHARED_SPLICE` 里没有新条目、`src/client/index.js`
  里也没有新标记。将来哪一票要拼，按 ADR §2.6 的两条边界条件办（产物是 ESM 且要用的东西都带
  行首 `export`；不含 `__DSW_VERSION__` 与 `__DSW_REPO_URL__` 两个占位符），并把那个产物的顶层名字
  加进 `tests/verify-generated-no-shadow.js` 的比对集合。本目录的转译已经把导出改成行首形式，
  第一条边界条件天然满足。
- 后端房间要 import 这份共享代码时，`tests/verify-no-cross-import.js` 的导入白名单要加一条
  `/^src\/shared\/refresh\//`——本票还没人引用它，所以白名单本票不加，接线那一票加。

## 日志点

核心是纯函数，自己不打任何日志：这里没有跨模块边界的调用、没有缓存、没有定时活、没有读写的动作，
照 `docs/design/335-logging-contract.md` 第 3 章的判定，一条日志点都不落在这里。
账本那三条事件（`quota.spend` / `refresh.decide` / `refresh.skipped`）的日志点归宿主侧那条链，
由后面的票接线；核心只提供它们要记的数字与结论。
