## 2. 不动代码的量法（开发者工具控制台，粘贴即用）

前置：打开宿主页面（DSH 对话页）的开发者工具，用“控制台”页签。两个量法互相独立，可以分两次做。
每次只记录“打开面板前后各 10 秒”这 20 秒窗口，窗口外的数据不要（定时刷新与后台探测会污染总数）。

### 量法一：长任务（`PerformanceObserver('longtask')`）

长任务定义：浏览器把主线程上超过 50 毫秒的一段执行记成一条 `longtask` 条目，
条目自带开始时刻（`startTime`）与持续时长（`duration`）。“整个 DSH 卡住的那几秒”就是这些条目加总。

步骤：

1. 控制台粘贴下面这段并回车（开始记录，20 秒后自动停并汇总；不改页面任何行为）：

```js
// 步骤 1：装好记录器（回车后 2 秒内做步骤 2）
window.__ltEntries = [];
if (window.__ltObserver) { try { window.__ltObserver.disconnect(); } catch (e) {} }
window.__ltObserver = new PerformanceObserver(function (list) {
  var es = list.getEntries();
  for (var i = 0; i < es.length; i++) {
    window.__ltEntries.push({ start: Math.round(es[i].startTime), duration: Math.round(es[i].duration) });
  }
});
window.__ltObserver.observe({ entryTypes: ['longtask'] });
window.__ltT0 = performance.now();
setTimeout(function () {
  try { window.__ltObserver.disconnect(); } catch (e) {}
  var total = 0, i;
  for (i = 0; i < window.__ltEntries.length; i++) total += window.__ltEntries[i].duration;
  console.table(window.__ltEntries);
  console.log('长任务条数 =', window.__ltEntries.length,
    '，总时长(ms) =', total,
    '，窗口(ms) =', Math.round(performance.now() - window.__ltT0));
}, 20000);
```

2. 回车后 2 秒内，用鼠标按当前待测状态做一次打开动作（三种状态见第 3 章）。
3. 等 20 秒倒计时跑完（期间不要打字、不要点刷新），抄下控制台打出的三行：表格（每条起止与时长）、
   条数、总时长，填进第 3 章对应格子。
4. 一个格子做三次，每次重新粘贴上面这段（每次都会清空上一次的记录）。

读数口径：总时长 = 窗口内全部长任务 `duration` 之和；“时间花在哪一段”目前只能靠
“条目开始时刻落在点击后第几秒”粗判，精确到 A–F 哪一段需要配合第 2.3 节的四行日志，
而那需要打开调试开关（见 F3），本次没做，记在第 5 章“没量到”里。

### 量法二：双层 `requestAnimationFrame`（打开到内容可见的耗时）

原理：与 B1 同一招——两层 `requestAnimationFrame` 保证“内容挂上并提交后再过两帧”，
此时读表即约等于用户看到内容的时间。含人工“回车后去点鼠标”的延迟（约几百毫秒），
同一人、同一手法下三态之间可比，不与别人的绝对值比。

步骤：

1. 控制台粘贴下面这段并回车，然后立刻用鼠标做一次打开动作：

```js
// 步骤 1：记下起点并安排“内容两帧后”读表（回车后立刻做步骤 2）
window.__openT0 = performance.now();
requestAnimationFrame(function () {
  requestAnimationFrame(function () {
    console.log('打开到内容可见约(ms) =', Math.round(performance.now() - window.__openT0));
  });
});
```

2. 抄下打出的毫秒数，填进第 3 章对应格子的“双帧可见耗时”列。
3. 一个格子做三次，每次重跑这段。
