- 关票工具支持 `closeReason`：地图子票写进 Answer 段并在地图补决策指针，实施票追加成评论，旧布局写 Close reason 行（#1495）。

- deck 工具的范围参数统一成 `effort` 与 `feature`（#1485）。
- `deck_issue_patch` 的工具定义拆成单独文件 `issue-patch-definition.ts`，`issue-patch.ts` 从 359 有效行降到 319（行为零变化），文件粒度门禁回到绿。

# Changelog

格式为 Keep-a-Changelog 子集：有新版时面板第 02 章更新日志自动展示本文件对应版本一节；缺文件或取不到时只给中性提示，安装不受影响。分类用 Added、Fixed、Changed、Security 必显展开，Deprecated、Removed 折叠，Unreleased 与空节忽略。

## [1.9.0-beta.17] - 2026-10-25

> 这一版把三组使用者能感觉到的改动一起发到 npm 官方源：本地账本不再把 GitHub GraphQL 调用记成 REST 请求（#1482）、改票关票之后面板不用等整份重建（#1472）、同一工作区多会话时链快照不再串沙箱判定（#1483），另补齐会话号转发（#1478）。

### Fixed

- 本地账本把 GraphQL 调用记成 REST 请求、把 rest 桶虚增到写保留线以下、进而把 deck 工具整体拒掉的问题修好：GraphQL 只记点数、按回包 `rateLimit.cost` 取真实成本（拿不到时按 1 点估并在日志里标 `estimate`），REST 才记请求条数；`gh.exec` 日志新增 `points` 与 `pointSource` 两格，能直接看出每笔记账是真实成本还是估算。
- 改票、关票之后面板要等兜底探测才刷新、连做多次写只刷新第一次的问题修好：写事件补取数做成真的（点名补行每次写都补、扫描类取数仍按 10 秒合并），下一次探针直接交回补丁。
- 同一个工作区开着两个会话时，链快照会把一个会话量出的沙箱判定（能不能写临时目录）当成另一个会话的答案；现在宿主按当前会话重算这几项，客户端跨会话命中先秒显再补问。
- 客户端第二个 `wf.chain` 调用点补上会话号，多会话时不再按错会话的沙箱许可判断（#1478）。

### Changed

- 写后刷新的取数失败统一走同一个出口（`refresh.patch` 记真实原因），失败原文里的绝对路径整段换成 `<path>`，不把工作区路径写进日志。
- 删掉 `deltaRefresh` 上生产入口从来不传的 `openSession` 守卫——它让行级增量在真机上恒回 `no-transport`。

## [1.9.0-beta.16] - 2026-10-24

> 这一版把四组改动一起发到 npm 官方源：布局答案只剩工作区文件一处真源（#1449）、刷新探测修好并把失败说出来（#1418）、deck 工具 `map-plan-create` 的边方向写清（#1421）、面板与状态栏胶囊共用取数时刻并带上两处体验修正（#1440、#1471、#1467）。

### Fixed

- 刷新后台的探测被 GitHub 单页条数上限整页拒绝、失败又只在日志里留一个散列的问题修好：翻页条数夹到 100、索引扫描带 `since` 增量窗口、被拒时自动降档重发并记 `read.degraded`；探测失败会在面板上如实显示原因，成功即撤。
- `deck_map_plan_create` 的 `edges` 方向写反问题：参数说明与回执都写清「谁把关系写进谁、朝哪边」；`type` 写成不认识的值以前会静默按阻塞边处理，现在整批拒写、一张票都不动（`deck_map_link` 同口径）。
- 面板与状态栏胶囊取数时刻不一致、304 快照回包缺工作区根的问题修好：两处改用同一个取数时刻并共用新鲜度配色，胶囊悬停能看到这个时刻。

### Changed

- 布局答案（初始化小卡问的「共用一套用语，还是各有各的用语？」）从此只存工作区文件（`docs/agents/workspace.yaml`）：换机器、换浏览器打开同一个仓库都不用重答；写不进去时界面如实提示「没有写入权限」，不再偷偷记在本机。旧的宿主 `choices.json` 与浏览器本地记录不再被读取，也不会被物理删除。
- 建议气泡浮层底色单独一档（深色更轻更透、浅色更白）；推荐下一步的提醒改成「回复前最后一步」的判断口径。
