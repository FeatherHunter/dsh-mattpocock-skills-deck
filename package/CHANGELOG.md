# Changelog

格式为 Keep-a-Changelog 子集：有新版时面板第 02 章更新日志自动展示本文件对应版本一节；缺文件或取不到时只给中性提示，安装不受影响。分类用 Added、Fixed、Changed、Security 必显展开，Deprecated、Removed 折叠，Unreleased 与空节忽略。

## [1.9.0-beta.12] - 2026-10-24

### Added

- Tracker 会话成为后端操作的唯一入口：九个 deck 工具、刷新后台的读写路径与宿主发布/认领/改色/命名守护统一经会话执行，不再各自选后端、过闸或直调 gh。
- 能力名录新增 `readBudget`（25 条变 26 条）：如实回答「还剩多少额度」——已知（双桶 / 只计请求 / 离网）或未知并说明原因；GitLab 后端补齐端到端。
- 状态胶囊上方「推荐下一步」气泡：每颗建议带一行简介、按条数均分宽度，出场动画放慢，选中后胶囊化作气泡上飘消失。
- 登录失败的黄条新增「重新检查」按钮，在横幅上就能完成人工重查。
- 状态胶囊第一帧先读本机工作路线，不再等整份快照重建。

### Changed

- **破坏性变更**：每个 Tracker 后端在注册时必须交出自己的 `budget` 预算模型声明，不交会注册失败；账本键从「两个桶」改成「后端 + 桶」（`github/rest`、`github/graphql`、`gitlab/requests`，Markdown 不建桶）。
- 未知额度、离网与已知耗尽分开说：回执与日志带 `backendId`、`budgetKind`、`readKnown`、`offNetwork` 四格，`remaining` 与 `tier` 只在读数真的已知时出现；未知预算模型不再静默，面板如实显示「额度未知：这个后端没有可用的预算模型」。
- 账本只有一个写入口：deck 工具路径与刷新后台路径的实际用量都经 Tracker 会话的操作管线记账。
- 更新入口全权委托给更新包：配置页检查更新按钮用包里的入口件默认摆法，更新面板用包的 dialog 原样；本仓不再自带按钮状态机与浮层弹窗。

### Fixed

- 没装 gh 的机器上用本地 Markdown 工作区时，九个 deck 工具不再被误判成「读的额度已用完」而推迟。
- 推荐下一步选项框只显示简介，理由收进框正上方浮层。
- 深色外观残留五项收口；浅色外观对比度修正；PTC 预设下建议气泡不出现的问题修好。

## [1.7.43] - 2026-10-06

### Added

- 版本管理页新增更新按钮：只取回远端跟踪引用，不合并，不碰工作树；成功后自动重读，身份行领先与落后即为本次更新后的数量。

### Changed

- 构建默认不再同步已装插件目录，新版本只由人自己升级。
