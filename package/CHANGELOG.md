# Changelog

格式为 Keep-a-Changelog 子集：有新版时面板第 02 章更新日志自动展示本文件对应版本一节；缺文件或取不到时只给中性提示，安装不受影响。分类用 Added、Fixed、Changed、Security 必显展开，Deprecated、Removed 折叠，Unreleased 与空节忽略。

## [1.9.0-beta.13] - 2026-10-24

### Added

- 下一步建议可以排优先级：`suggest_next_steps` 每条建议可选 `priority`（0 到 10 分），界面按分从高到低往左排，没打分的排最后。
- 理由浮层里先显示推荐分数、再显示理由；选项框与浮层加了磨砂底。
- 下一步建议优先从技能角度给：工具说明、参数与 `/ask-matt` 规则统一要求提示词开头写 `/xxxx` 技能。

### Changed

- 下一步建议气泡的锚点从状态胶囊改为跟输入框走，输入框高度变化时自动重新量位置。

### Fixed

- 登录状态黄条在环境检查还有一步没确认时误显示成 8/8 全绿、点「重新检查」没有反应的问题修好。
- 点开票详情报 `repo.refId missing`、只剩短名读不到票面的问题修好；详情与评论的读路径改用只读会话补好的仓库引用。

## [1.7.43] - 2026-10-06
