---
name: handoff
description: 把当前这次对话压缩成一份交接文档，供另一个代理接手。
argument-hint: "下一次会话要用来做什么？"
disable-model-invocation: true
---

写一份交接文档，总结当前这次对话，好让一个全新的代理能接着把活干下去。把它保存到用户操作系统的临时目录（`$TMPDIR`，没有就用 `/tmp`；Windows 上是 `%TEMP%`）——不要保存到当前工作区。

在文档里加一节「建议调用的技能」，写明下一个代理应当为哪些技能调用 Skill 工具。

不要重复其他产物（规格说明、计划、ADR、议题、提交、差异）里已经记下的内容，改用路径或 URL 引用它们。

任何敏感信息都要脱敏，例如 API 密钥、密码或可识别个人身份的信息。

如果用户传了参数，就把它们当作对下一次会话关注点的描述，并据此调整文档。
