# 阶段边界

**阶段**是会话内的一块工作：盘问、实现、验收。这个定义是故意模糊的：当你想*「好，这块做完了」*的时候，一个阶段就结束了。

**阶段边界**是两个阶段之间的空档，也是这个决定唯一该做的地方。阶段中途没有决定可做：要么继续，要么把剩下的工作拆成子代理。在阶段中途压缩，会让代理丢掉正在跟的思路。

## 五个选项

| 选项         | 它做什么                                                          |
| ------------ | --------------------------------------------------------------- |
| **继续**     | 留在当前会话。完全不做上下文切换。                                |
| **`/clear`** | 清空上下文窗口，从零开始。                                          |
| **`/handoff`** | 写出一份可携带的 Markdown 文件，在任何地方用它给一个会话打底。      |
| **子代理**   | 把任务送到它自己的上下文窗口，再拿一份报告回来。                    |
| **`/compact`** | 压缩这份上下文，并用摘要给一个新会话打底。                        |

## 决策树

在边界上从上往下走。第一个**是**胜出。

**1. 你能在这次会话里继续吗？** 有两件事会让答案成为「是」：下一阶段需要这一阶段作为**一手来源**；或者你剩下的[智能区](https://www.aihero.dev/ai-coding-dictionary/smart-zone)还够（约 150k tokens）装下下一阶段。盘问 → 实现 是标准的「是」：实现要的是这份推理的原文，而不是它的摘要。继续不花成本，也不丢东西，所以在考虑其他选项之前，先把「继续」排除掉。

**2. 上下文与接下来的事无关吗？** 这次会话里的一切（探索、决定、死胡同）都可以丢掉吗？如果是，就 **`/clear`**。它是棋盘上最便宜的一步：不花时间，还把整个窗口还给你。`/clear` 也不是终结：旧会话仍然可以恢复。

这一步弄错的代价是单向的。清掉一份*相关*的上下文，你就丢掉了所建之物背后的**为什么**，而且无论怎么反复读 diff 都找不回来。

**3. 你需要做交接吗？** `/handoff` 的适用范围很窄。只有这几种情况你才需要它：

- 换到一个**新的运行环境**（Claude → Codex），
- 搬到**新目录**或新仓库，
- 把工作交给一位**同事**，
- 或者在**阶段中途**发现了一个侧任务，想把它分叉出去又不打乱手头的事。

这份清单就是全部条件。`/handoff` 换来的是**可携带性**：一份能随身携带的文件。如果没有东西要带走，你就不需要它。

**4. 这个任务能在 AFK 时做完吗？** 它的范围收得够紧吗——紧到你离开键盘、不用你掌舵也能跑？如果是，就把它交给一个**子代理**，这次会话原封不动。自动评审是标准例子：代理读 diff 并报告，它做的时候不需要你在场。

**5. 否则就用 `/compact`。** 上下文相关、同一个运行环境、同一个目录，而你又需要留在回路里：决策树就落到这里，而且经常落在这里。给它一句话说明（`/compact we're going to QA this area`），让摘要保住下一阶段需要的东西。

`/compact` 是**默认选项，但不是第一个伸手去拿的**。它坐在最底下，因为它上面的四个问题都更便宜、或者更精确。人们一上来就用它时，典型的失败是：换来的新会话对某个被摘要压平的决定，极其自信地判断错了。

## 一手来源与二手来源

除了**继续**之外的每一个动作，都会把一份**一手来源**变成**二手来源**：原本如实发生的那次会话，被它的摘要取代。这笔交换的形态永远一样：

| 来源                            | 信息        | 噪声  | 回旋余地     |
| ------------------------------- | ----------- | ----- | ------------ |
| 一手（继续）                      | 完整        | 多    | 少           |
| 二手（`/compact`、`/handoff`）    | 有损        | 少    | 多           |

这就是为什么第 1 个问题排在最前面。只有留下来的代价大于它省下的东西，你才需要承担这种有损。

## 这些都需要判断

这些问题都不客观：每一个都带着需要靠品味判断的成分，同一个阶段边界，隔两天可能就得出两种答案。它的价值在于**按顺序**问它们，并且在边界上问，而不是在工作做到一半时问。
