disable-model-invocation: true
---

把用户在规格说明或工单里描述的工作实现出来。

如果用户递来的是一个工单引用，先从议题跟踪器把它取回来，并在动手之前说明它的标题。如果这个引用指代不明，就问清楚。

尽可能在事先约定好的接缝处，用「tdd」调用 Skill 工具。

定期跑类型检查，定期跑单个测试文件，最后完整跑一遍整个测试套件。

做完之后，用「code-review」调用 Skill 工具，评审这次的工作。

把工作提交到当前分支。
