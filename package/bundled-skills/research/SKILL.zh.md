---
name: research
description: 针对某个问题去查高可信度的一手资料，并把结论写成仓库里的一个 Markdown 文件。当用户想研究某个主题、收集文档或 API 事实，或者想把查阅资料的体力活交给后台智能体时使用。
---

开一个**后台智能体**去做这项调研，这样它在读资料的时候你还能继续干活。

它的任务：

1. 针对**一手资料**（官方文档、源代码、规范、第一方 API）去调查这个问题，而不是读别人对它们的二手转述。每一条说法都要追回到拥有它的那个源头。
2. 把调查结果写进单个 Markdown 文件，每条说法都注明来源。
3. 存到仓库本来就存放这类笔记的地方；沿用既有约定，如果没有这种约定，就放到一个合理的位置并说明放在哪里。
