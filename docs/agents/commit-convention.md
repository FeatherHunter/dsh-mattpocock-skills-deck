# 提交信息规范

所有 `git commit` 信息必须用中文，用通顺的完整句子说清“这次改了什么、为什么改”。

## 规则

- 标题至少 10 个字，用完整句子，不要只写 `fix` / `update` / `feat`
- 允许保留必要的英文术语（如 `API`、`GitHub`），但主体必须是中文
- 正文如需补充，也请用中文写清背景与影响

## 好例子

- `修复：修复切换仓库后面板仍显示旧数据的问题，避免用户看到过期状态`
- `新增：为环境检查链增加等待提示，让用户知道正在检测通用依赖`
- `说明：定一下提交规矩，以后都用中文说清楚改了什么`

## 差例子（请勿提交）

- `fix bug`
- `update`
- `feat: add feature`

## 给 AI 的提醒

生成提交信息时直接写中文标题，标题里要包含动词与对象，例如“修复……”“新增……”“把……改为……”。
