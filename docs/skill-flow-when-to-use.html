一句话：triage 与 wayfinder 是起点（贴标签 / 产决策），to-spec / to-tickets / implement 是主路径（消费 ready-for-agent 去落地）。前两者定义标签，后三者消费标签。

Wayfinder 是最重的起点：When the map clears, it hands off, it doesn't build: merge onto the main flow at /to-spec —— 雾清后必须先 to-spec 再 to-tickets，直跳 implement 会丢掉 Decisions so far。仅当它在第二步就判定“无雾、小活”时才可不经 to-spec 直 implement。

为什么那张“100% 逐字表”只出现 2 个技能

  • 那张表是“标签是谁定义的”—— triage 定义五态，wayfinder 定义 wayfinder:*，setup 把默认字符串 1:1 落盘到 triage-labels.md。后三者（to-spec / to-tickets / implement）不定义新标签，只消费 ready-for-agent 去干活，故不出现在“标签定义表”。
  • 若把“标签驱动谁”也列上，才会出现五技能对照——即本表。
