Lesson 02 · 12 min · Hands-on

30 秒配好你的仓库
/setup-matt-pocock-skills + /ask-matt = 从此不迷路

所有 skill 都假设三件事已被回答：票在哪、标签叫什么、词在哪。这一课把它们落盘到 docs/agents/*.md。

为什么必须先配： 不跑 /setup-matt-pocock-skills，后面每个 skill 都会先问你“你的 tracker 是什么？”——等于每张票都重新争论一次。
  • Issue tracker：票落在哪（GitHub / GitLab / 本地 .scratch）
  • Triage labels：五枚状态的“真名”叫什么（默认 needs-triage 等）
  • Domain docs 布局：单上下文（CONTEXT.md + docs/adr/）还是多上下文

三种 tracker 的取舍

Tracker何时选blocking 形态
GitHub有远端、想让票在官方 UI 可视化原生 dependencies
GitLab远端在 GitLabglab 对应能力
本地 .scratch单人练习、无远端每票一个 .scratch/<feature>/issues/01-*.md

真实运行长什么样（本仓已跑过的证据）

docs/agents/issue-tracker.md  — GitHub 为 tracker
docs/agents/domain.md         — 单上下文：根 CONTEXT.md + docs/adr/
docs/agents/triage-labels.md  — 必选三枚：bug / needs-triage / wayfinder:grilling
cat docs/agents/issue-tracker.md | head -40
gh issue list --state open --json number,title,labels --limit 5

本仓的选择：单上下文 + GitHub。

三步，配你的仓库

1
装 skills
npx skills@latest add mattpocock/skills
claude plugins install mattpocock-skills
npx skills update

可改流的好处：你能按团队习惯改拷问清单。

2
跑 /setup-matt-pocock-skills

在 Agent 里敲：/setup-matt-pocock-skills

  • Section A：tracker 选型（它会先读 git remote -v 再给推荐）
  • Section B：仅当已装 triage 时出现
  • Section C：默认单上下文；仅在真 monorepo 时才问多上下文
3
验证 + 学会 /ask-matt
cat docs/agents/issue-tracker.md
cat docs/agents/triage-labels.md

此后任何时候不知道“该用哪个 skill”，敲 /ask-matt。
