#998 · BUG · 2026-10-10

工具整片被“连续失败”锁死：现状与三个遗留问题的计划

现象 → 根因 → 已落地的修复 → 三份深查证据 → 按第一性原理的后续计划。从“失败必须退避，同时必须可恢复”出发。

bug ready-for-agent 修复 71dbc3e 已合入 · v1.8.0-beta.4 半开门禁 29/29 通过

一、现状：发生了什么，现在在哪里

第一性原理：闸同时守两条纪律——失败必须退避（不许风暴），失败必须可恢复（锁必须有出口）。#998 是第二条断了。

现象同一工作区所有 deck_ 工具回同一句“连续失败到了退避门槛”（gate-defer）。建单时 5 次跨 15 分钟必现；日志里 19 条工具失败落在 12:33–12:49，同期闸裁决反复写 failure-backoff 且档位是绿的——额度不缺，只被计数挡住。
根因（已证实）连续失败计数自锁：真失败加一、只有真成功才归零，被推迟的调用既不加一也不归零。到门槛后所有调用在选后端一步就被推迟，永远没机会成功归零。12:41 后再无真正花费，12:42 后传输已恢复但工具仍被推迟到 12:50。建单时的“进程里没有 gh”候选已被否（活日志解析失败 0 次、1333 条成功）。
已落地半开探针：退避走完一整轮放一笔进来试，成功当场解锁，不成按退避档继续等且越试越稀；在飞不放第二笔；被推迟仍不加计数。重启后上报成功、取现状成功（39 张地图）、failure-backoff 归零。探针自愈路径本身尚未被真机自然触发，判据是下次连续失败时日志出现 failure-half-open 随后计数归零。
主验收已过：重启后工具恢复 + 29 项门禁全绿 + 构建通过并同步桌面端。本票保持 bug + ready-for-agent，等自然失败观察，不阻塞。

二、三份深查的结论（只读一手来源，每条带出处）

三份报告在 research/998-q1-*.md，结论先行，细节见文件。

Q1 · 共用一个计数单计数是写死的：gate.js:124 一区一行一数，policy.ts:74-75 门槛 3。账本分三档两桶，熔断不分档。日志缺“3 次是谁”，1098/116/19 无日志原文，snapshot 疑似本地读。结论：先补归因，不直接分。
Q2 · 冷却锚不推进锚只在首次失败盖戳（deckQuotaSync.js:120），过期后每调用必起 gh；单例全进程共享，A 区失败冷所有区；五档失败混用 60 秒；关键路径每笔先等保读数。结论：两步走，先滑动锚一行，再分区 + 解耦。
Q3 · 超时归因不清末条 backend-threw 与 gate-defer 不是同一条路（发了没回来 vs 不让发）。外层 120 秒 / 单操作 30 秒包全轮，全量多页串行偏紧可证；那一次缺操作名 / 耗时 / 哪层掐的，不可定性。结论：窄单先埋点再等复现。

三、计划：按“先止血，再看清，再动形状”排序

不计成本、只求长期正确，但不镀金：观测先行，形状后动；每一步可独立合入、可回滚。

1
Q2 第一步：滑动冷却（一行，立刻止血）

把“锚是 0 才盖戳”改成“每次失败盖本次戳”；门禁加“过期后连续失败仍按 60 秒节流”。效果：过期后失败出站从每分钟 R 次降到约 1 次，gh.exec 噪音减少。风险近零。

2
Q1 归因 + Q3 埋点（只加观测，不断行）

Q1：在裁决与跳过日志里带“当时几次 + 上一笔真失败是谁”，终结闭眼调参。Q3：在已有两行与壳失败行里补操作名 / 真耗时 / 哪层掐的 / 折前细码（只记枚举数字散列，不记原文）。两张都不改阈值、不改重试。验收：下次锁住或超时能回答“是谁、等了多久、谁先掐的”。

3
Q2 第二步：分区 + 关键路径解耦

冷却按工作区分锚；有旧读数先放行、同步放后台；完全无读数也不挡路（剩余恒 0 等也白等，直接诚实推迟、后台去刷）。附带：落账加时间戳比对（旧不盖新）、后台失败界面可见、不新增事件名。指数退避与抖动暂缓；硬软分级只做最粗一档（无 gh 等很久）。

4
Q1 是否真分：按数据再定

前置三条缺一不可：锁住的几次里两组病因不同类已证；面板“后台几组、工具几组、谁在等”三句话文案先定；门禁按组钉住组间不串。否则不分——单数 7–10 分钟一笔是最硬上限，分组会乘以组数，且需另加合并告警。

共同的不做：不重开 #427/#702 的寻址讨论；不合并 #893（断 vs 慢是两种失败模式）；不动 #930/#916/#960；不在 #998 本体里顺手改。三张新票互不阻塞，均为 bug → ready-for-agent。
需要拍板的：① Q1 归因单是否开（推荐开，分桶功能单不开）；② Q2 一行止血 + 分区解耦是否开（推荐开）；③ Q3 窄单是否开（推荐开，复现不到只留埋点）。回复即按此建票，#998 本体不动。
