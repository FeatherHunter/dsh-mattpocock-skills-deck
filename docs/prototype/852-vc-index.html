版本管理面板 · 界面全集

这一组是**设计稿**，不是产品页面。目的是把版本管理这个功能里每一个页面、控件、按钮、提示都画出来， 让人在验收之前就能一次看全，而不是只看得到其中一页。每一项旁边都标着它在产品里的词条键， 键名可以直接在源码里搜到：src/client/views/versionControl/ 与 src/client/kernel/locale-*.js。

P1控件图鉴

面板里每一个控件：顶部三个动作、暂存与提交、提交说明输入框、确认块的各档、进行中与完成回执、15 类失败提示、状态徽章、异常带、链接、空态、加载骨架、读不到的 14 种说法。控件之间怎么排，一格一格摆出来。

vc.action.* · vc.confirm.* · vc.op.* · vc.writeErr.* · vc.change.* · vc.block.* · vc.fail.*

P2只读全景

只读状态视图的全部状态各画一屏：干净、有改动（满屏与两种瘦态）、冲突、四种进行中操作、游离头、无上游、上游被删、落后远端、裸仓库、不是仓库、没装 git、git 太老、还没有提交。含 380 与 300 的让位。

vc.changes.* · vc.group.* · vc.band.* · vc.sync.* · vc.basis.* · vc.staleHint

P3写操作全景

暂存 / 全部暂存 / 提交 / 拉取 / 推送五个动作的完整链路：输入框各态、拉取与推送的各档确认、多远端时的远端选择、每档推送对应的完成回执，以及被拦住时那一行「接下来该怎么办」。

vc.action.* · vc.commitArea.* · vc.confirm.* · vc.pickRemote.* · vc.writeErr.* · vc.op.done*

P4差异与历史

差异的九种形态（加载中、空、二进制、过大、合并提交、没有基线、未跟踪、读失败、截断提示）、提交里看某个文件、提交历史的四种状态（加载中、读失败、加载更多、已经到底），以及其他工作树的九种情形。

vc.diff.* · vc.commits.* · vc.commit.* · vc.other.*

更早的那份原型（只读状态视图的三款视觉变体）

  • 815-readonly-3variants.html —— A 编辑留白 / B 纪念碑 / C 档案索引；可切 ?variant=A|B|C 与 ?state=dirty|clean|rebase|nogit|nogitbin。
  • 本组原型用的视觉语言就是那一页里的 C 档案索引：等宽路径、字母徽章、细分隔线、右对齐正负行数。
  • 页面里那条红色「抛弃式」标记、深浅色切换、键名标注，都是脚手架，不是要上线的界面。
