地图详情页重做原型 · 清晰的目的地 ＋ 诚实的雾 ＋ 走亮的路

要回答的问题：地图详情页该用什么形态，让人一眼看到终点、同时诚实看到「哪里我还没走过」，并且把走过的路留成一条亮痕？

现有页面把每张票平铺成一个方块：已走的、没走的、被挡住的看起来一个样；底部的进度环按「层」算，所以单层地图永远是满环；而 issue #474 要的迷雾，在真机上一次都没有出现过（原因见下）。
真机取证的页面
地图 #604（4 层 · 4 张票）· 面板宽 810px
迷雾为什么没渲染
子票的 number 是数字、blockedBy 里是字符串，严格比较永不相等
进度环为什么失真
环按「已通过层数＋1／总层数」算：单层地图永远满环
第一层闸门为什么总是绿勾
「前面所有层都关了」在 0 个前层时天然成立

下面三个变体用同一份真数据（地图 #604 的 Destination / 子票 / 战雾条目原文）表达同一套状态语义， 只是形态完全不同：A 行进线把票当路线上的站点、B 迷雾地图画成一张真正盖着雾的图、C 清单账本压成一张按「现在能不能做」排序的密集清单。 底部控制条可切变体、切状态（空图／推进中／已走亮）、切面板宽度（400／560／810），并可试「一键全亮」和「非颜色区分」。
