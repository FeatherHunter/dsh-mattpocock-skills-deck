[P1] Map 行响应式布局定版 — 编号横排/竖排 + 行2间隙收紧

聚焦 右侧主面板列表 `ListTab` 的 `issueRow`。目标：标题一行放得下 → 编号横排到地图右侧；标题需两行/面板极窄 → 竖排，并在极窄/极宽护栏与行2全局收紧上定版。原型为可拖动滑杆缩放的真实行渲染（复用内核样式），T1 按此落地。

定版摘要（给 T1 直接落地）

三项定版 + 一项对齐规范。数值均以行内容可用宽度（`.dsws-aggrow` clientWidth）计量，括号内为约等面板宽度。
① 横排 / 竖排条件 — 标题适配
若 横排 idcol（地图|编号）后标题仍能一行放下 → 横排 ；否则 竖排
实现：JS 测量 — 先将 idcol 切横排，用 white-space:nowrap 测标题 scrollWidth ≤ clientWidth 即一行放下。保留 -webkit-line-clamp:2 时，仅判定用 nowrap 测量，不改渲染 clamp。
② 护栏阈值 — 宽度护栏
极窄 < 320px 一律竖排 （≈ 面板 < 360px）
极宽 ≥ 440px 一律横排 （≈ 面板 ≥ 480px）
中间区间 [320, 440)px 走①标题适配。默认面板 460px→行约 423px 落在自适应区，符合“默认走标题适配”的预期；窄阈 380 对应行约 340px 仍自适应，仅 极窄才强制竖排，避免短标题在极窄下被挤到 77px。已在下方滑杆标出。
③ 行2 收紧间距 — 全局统一
8px （.dsws-aggrow gap 6px + 行2 marginTop 2px）
现状 14px（gap 6 + marginTop 8）→ 收紧至 8px（-43%），仅改 marginTop:8→2，保留 gap 6 的结构间距。所有行一致（Map / 普通 / 已关闭）。下方可对比 14px / 8px。
④ 对齐与间隙（横排态）
idcol↔标题 8px  |  标题↔圆环 8px  |  idcol 内横排 gap 6px / 竖排 gap 3px
行1 align-items:flex-start，idcol 横排时 align-items:center；标题 flex:1; min-width:0; line-clamp:2 不被压缩；圆环 flex:none; min-width:35px 与编号保持 gap，不粘死
超长标题 clamp 2 行可读，idcol 横排不挤压标题；圆环右缘对齐（tabular-nums 5ch），各行右缘对齐。
T1 落地清单：styles.js 新增 .dsws-idcol.h 横排变体；ListTab.js 行1容器 gap:6→8，行2 marginTop:8→2，并注入上述 JS 测量（ResizeObserver + window resize + 首次渲染）。双源 node scripts/build.mjs 重建。

ListTab.js · 测量（伪码，可贴）
function applyRowLayout(rowEl){
  const avail = rowEl.clientWidth; // 行可用宽度
  if(avail < 320) return setH(false); // 极窄护栏
  if(avail >= 440) return setH(true);  // 极宽护栏
  const title = rowEl.querySelector('.dsws-tt-wrap');
  const idcol = rowEl.querySelector('.dsws-idcol');
  idcol.classList.add('h'); // 试横排
  title.classList.add('measure'); // white-space:nowrap 测单行
  const fits = title.scrollWidth <= title.clientWidth + 1;
  title.classList.remove('measure');
  if(!fits) idcol.classList.remove('h');
  function setH(on){ idcol.classList.toggle('h', on); }
}
// 监听：ResizeObserver(rowEl) + window resize + 首次渲染后 layoutEffect
