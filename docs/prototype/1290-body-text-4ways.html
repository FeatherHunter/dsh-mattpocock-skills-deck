主体文本重新设计：四个方向

前一版的思路整体作废：不再在「做法 + 产物」这一条路上挑措辞，也不再在「心里话 / 开场白 / 处境加后果」那三个框架里挑。下面的四个方向给主体文本的是四个不同的职责，不是同一句话的四种写法。

为了能横向比，只换主体文本这一块：眉标（探索地图 / 实施地图）、状态句（目标大而模糊 / 目标明确清晰）、左上角那幅地图、底部那条技能链、卡片骨架与配色全部照旧。

四个方向各自回答的问题：一 · 对话——这路会问我什么；二 · 分工——你做什么、它做什么；三 · 准备——我得带上什么才能走；四 · 形态——这路长什么样。

一对话 · 这路会问我什么

主体文本不描述步骤，改成把这条路将来怎么对你说话说出来：它来问你，问的是哪件事。两张卡的第一句就能分开——「会分头问你」对「会照着文档问」。

二分工 · 你做什么、它做什么

主体文本只画人和工具的边界：哪一段是你的活，哪一段是它的活。排在卡上是两色——「你……」用卡色淡一档，「它……」用灰，一眼能看出活落在谁身上。

三准备 · 我得带上什么才能走

主体文本回答开始之前手上该有什么：探索这条路几乎不用准备，实施这条路要带一份文档。这条直接对着「我什么都没有，能不能开始」这个顾虑。

四形态 · 这路长什么样

主体文本用文字把卡上那幅图画的东西再说一遍：一条路分成三条岔路，每条尽头一个问号；一条直线一路问到盖章。

对照四个方向放在一起比

我的倾向是方向一（对话）：它同时把两件事说了——这条路是来问我的（这层心理准备最有分量），以及问的是什么（分头问 / 照着文档问，两张卡开头就分得开）。方向二（分工）是第二选择，它把「决定权在你手上」这件事摆得最清楚，但要引入两色排版。方向三只对新用户有用；方向四跟插图重复，是四个里最弱的。
