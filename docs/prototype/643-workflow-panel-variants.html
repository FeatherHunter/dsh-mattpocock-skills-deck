原型 #643 · 把底部那颗紫色按钮打开后的东西，改成「一块一块工作流」

这是给眼睛看的假面板：没有后端、没有真实数据、刷新就回到初始状态。底下那条黑色小条是原型自己的切换器，不是设计的一部分。

这个原型要回答的设计问题
形状已经定了（2026-09-19 拍板）：走「大区域」这一档——屏幕居中一大块、尽量不用上下滑就能看全。 下面这些开关是在这一档里继续挑细节；小面板那一档留着做对照，切「形状」就能看到。
一、大区域里内容怎么摆：一条路一行（20 条路排成 20 行）、一颗技能一格（25 颗铺成网格）、还是分成块并排几栏。
二、找法：按「我现在要干什么」找、按「原作者官网的编号分组」找，还是把两者叠起来。
三、说明放哪、点完关不关、该点哪个要不要突出这些细节。
换三种找法：底部条左右方向键 ← → 形状 / 铺法 / 面板宽度 / 块数规模 / 技能行说明 / 技能排版 / 点完 / 该点哪个：并列开关 内容取自 research/642-aihero-workflows.md

引导场景 每个场景从干净状态开始，按顺序点，走完一遍就懂了

当前状态 每点一下都重新算一遍

「可见」= 面板一屏能露出来的那一截里，有多少块工作流能被看见；被折起来或滚到下面的不算。
「一屏能完整露出几块」在面板开着的时候是量出来的（面板里此刻真露出来的那一截）；面板关着的时候是估的，按每块展开后的高度累加，不含半个。
「一眼看全」只在大区域那一档出现：量的是面板里有没有藏起来、要滚才看得到的内容，直说还差多少像素。
「该点这个」那一行是绿的：原型里每一块都从第 1 棒开始标，点过一棒就往下走一格；真机上这一格该跟着会话走到哪儿。

怎么用这个原型 给拿主意的人

1. 先按 ← → 把三种找法翻一遍，看在同一个面板位置上，哪一种让你更快认出「我该点哪条」。

2. 把形状切到「大区域」：一大块地方居中摊开，看能不能把内容一次看全、不用上下滑；铺法有「一条路一行」与「一颗技能一格」两种，面板底部那行「一眼看全」会直说还差多少像素。看完再切回「小面板」对着比。

3. 在小面板那一档里把块数切到「20 条路一块一条」和「22 处归并成 20 块」，看折叠与滚动够不够用、要不要那个「一行一个工作流」的总览态。

4. 把技能排版切到「横向流水线」，看五棒折成一条链之后还认不认得出顺序；把该点哪个打开成「突出」，看那块绿是帮你还是吵你。

5. 把技能行说明切到「写在行里」，看行变高之后还认不认得、大区域里还放不放得下；把点完切成「不关，留回执」看注入之后想不想继续点第二个。

6. 窄面板那一档（260 与 200 像素）是照现在「文字收成图标」的行为摆的，看折到哪一档还能用。
