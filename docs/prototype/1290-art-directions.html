原型 · 两副 SVG 的三个方向（打样）

同一张选择卡，里面的图换三种画法。三种都遵守同一条约束：图里不写长句，只留 2 字的「需求」标签；文字在 HTML 里，缩到卡片真实尺寸也压不到画。

每副图都按真实尺寸（132×82）再放一遍，见每节末尾的「真实尺寸」一行——挑方向时以那一行为准，大图只是给人看细节。

文案试排：目的地要不要写成「技能链」

两种排法表达同一件事：点击之后会顺着哪些技能往下走。技能名后面跟中文释义，是因为插件界面上用户看到的就是这些斜杠技能。

探索卡 · 排法一：一行链
/wayfinder探索地图 → /to-spec转成规范 → /to-tickets拆成实施票 → 实施地图
探索卡 · 排法二：两行句子
从 /wayfinder 开始，先把探索地图探到位；之后经 /to-spec、/to-tickets 走进实施地图。
实施卡 · 排法一：一排技能链（带中文释义）
/grill-with-docs拷问设计 → /to-spec转成规范 → /to-tickets拆成实施票 → /implement逐票实施
实施卡 · 排法二：竖排四步
  1. 1/grill-with-docs拷问设计，把没想透的地方挑出来
  2. 2/to-spec转成规范
  3. 3/to-tickets拆成一张张实施票
  4. 4/implement每张实施票执行一次实施
