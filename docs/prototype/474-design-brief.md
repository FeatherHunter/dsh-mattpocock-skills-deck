## 1. 这是什么产品

`dsh-mattpocock-skills-deck` 是一个装在「DeepSeek Harness」桌面应用里的插件。它在应用**右侧边栏**里画一块面板（宽 360–810 像素，由用户拖），
把仓库里的 issue 当成「票」展示。面板的入口是状态栏上的一颗胶囊，用户点开它、进到「地图详情页」。

**「地图」是什么**：仓库里有一类 issue 打了 `wayfinder:map` 标签，它是一张「导航图」——它有一个**目的地**（写在正文的 `## Destination` 一节里），
下面挂着一批子票（子 issue）。子票之间有阻塞关系（`blockedBy`）：A 没关掉，B 就动不了。

**这一页要回答四个问题**：终点在哪 / 我现在能做什么 / 哪些路还没走过 / 走过的路留下了什么痕迹。

**这一页的硬约束（真机实测定的）**：点开面板到看见内容 **≤ 300 毫秒**。因此：
**不许引入任何第三方库、不许联网、不许用 CDN。** 一个 HTML 文件，双击就能打开，全部代码自己写。

## 2. 设计理念（来自 issue #474，维护者原话）

> 「**目的地清晰而模糊**」：目的地是清晰的（比如「去泰国旅游」，到泰国这件事明确），通往它的路是模糊的（怎么去、哪条通哪条不通，全是待探索）。
> 一张诚实的地图必须同时呈现这两样：**看得见的终点，和诚实的未知**。否则用户会误以为「都规划好了」，推进全靠脑补。

五条必须守住的语义：

1. **终点永远清晰**：不管雾怎么盖，目的地节点始终明亮可见。
2. **未知必须诚实**：没走过、走不通、还没想过的地方要看得出是「不知道」，不能伪装成待办。
3. **走亮留痕**：走过的路连成一条痕迹，回头看就是「我认真探索过的领域」。
4. **雾本身是信息**：想过但没走通的分支继续盖着雾，不为了「全亮」去走没意义的路。
5. **不许只靠颜色区分状态**（色弱用户）：形状、纹理、文字、图标至少再占一样。

## 3. 票的四个状态（全项目统一，不许改语义）

| 状态 | 判定 | 含义 |
|---|---|---|
| **走亮** | `state === 'CLOSED'` | 已经走完的路 |
| **照亮中** | 开着，且有 `claimedBy` | 正在推进的那一张，周围是「视野」 |
| **现在能做** | 开着，没人认领，且它的阻塞者全都关了 | 现在就能开工的下一站 |
| **雾里** | 开着，且它至少有一个阻塞者还开着 | 路画出来了，但通不通不知道 |

派生量：**层**＝按 `blockedBy` 算的最长路径深度（层 0 是最靠近起点的第一层，层号越大越靠近终点）。同一层内的票可以并行。

## 6. 六个人分别做什么

### 三条探案板优化线（同一个隐喻，三种改法）

维护者只认一个方向：**探案板**——把票当成钉在软木板上的卡片，用红绳表示「谁挡着谁」。他觉得这个方向好看、有创意，但有 bug。三个人的任务是**从三个不同角度把它做好**：

**P1 · 精修证据墙**：概念不变，把工艺做到位。
- 卡片按层分行，行内均匀排布；**卡片不许重叠**，票从 4 张到 20 张都要好看（20 张时可以分组折叠）。
- 红绳走线要有规则：正交折线或圆弧绕行，**不许穿过任何卡片**，并且能看出「从谁到谁」。
- **卡片整体可以微转（±2°），但文字必须水平**（现在整张卡连字一起转，读起来累）。
- 补齐键盘可达性（Tab 能到每一张卡，回车等于点击）、hover/focus 态、以及「只靠颜色不够」的纹理/字形补充。
- 雾里的卡片要有物理感：像还没拆开的信封/证物袋，点一下才有反馈动画。

**P2 · 时间线证据墙**：卡片不再散落，而是**挂在一条主轴上**（轴从左到右＝从第 1 层到最后一层）。红绳从轴上方/下方绕出去表示依赖。
- 好处：一眼看出「走到哪一段了」；主轴本身就是「亮痕」。
- 雾＝主轴末端还没到的那一段盖着**封条**，撕开封条才看得见下面的卡。
- 仍然保留软木板、图钉、红绳这些材质。

**P3 · 卷宗柜 ＋ 全部技法**：把探案板推到「档案柜/卷宗」的物理世界里：每一层是一个抽屉/档案袋，卡片是袋里的物证。
并且**必须把下面五条技法全用上**（它们来自对六个前端库的调研，参考实现见 `docs/prototype/474-map-detail-craft.html` 与 `docs/research/474-frontend-craft.md`）：
1. **雾＝整张遮罩挖洞**（不是往未知处刷雾团）：Canvas 上铺满雾，再用 `globalCompositeOperation='destination-out'` + 径向渐变把走过的地方擦成柔边洞（学自 Leaflet 的多边形挖洞 / PixiJS 的 destination-out）。
2. **状态色按明度阶梯排**（相邻 L\* 差 ≥10），并给出「红/绿/蓝三型色觉模拟」开关（学自 Chroma.js 的判据）。
3. **扫亮动画**：亮痕用 `stroke-dashoffset` 一段段扫过去（学自 Anime.js 的 stagger）。
4. **边角控件栈**：右下角一列小方块（聚焦当前 / 一键全亮 / 图例 / 缩放），底部一条数据条（学自 Leaflet 的控件）。
5. **进度环按票分段、环心写字**（学自 Chart.js 的甜甜圈；现在线上那个环是按「层 +1」算的，单层地图永远满环，是错的）。

### 三条天马行空线（换一个完全不同的世界）

**W1 · 矿井剖面（向下掘进）**：把地图当成一条往地下打的矿道。
层＝深度（第 1 层最浅，越深越接近矿脉）。已开掘的巷道亮着矿灯、有轨道与支撑架；正在挖的那一段有钻机与扬尘；没动的是完整岩层（要用地质剖面图的语言画：岩层纹理、断层线、错动）。
**目的地＝矿脉**，永远在剖面上标着（哪怕还隔着几十米岩层）。
「不知道」在矿井里天然成立：岩层里的东西本来就要挖开才知道——雾＝未开采的岩层，切面上画斜线纹理。

**W2 · 机场航班信息板 ＋ 塔台**：把地图当成一块出发信息板。
每一张票是一个航班，状态天然就有：`已到达`（走亮）／`登机中`（照亮中）／`准点`（现在能做）／`待定`（雾里）。
字体用等宽、翻牌式的行（黑底黄字那种质感可以有，但要在深色 UI 里和谐）。
再加一条**跑道视图**：一条细长的跑道横贯面板，走到哪一段了在跑道上标出来，目的地是跑道尽头的灯。
信息板的好处：一屏能放下 20 个航班，而且「待定」这个词本身就是诚实的。

**W3 · 量子概率云（观测即坍缩）**：把「未知」做成真的物理隐喻。
已定的票是**确定态**（清晰的圆点与实线）；还没定的票是一团**概率云**（粒子、模糊、位置抖动）；
用户**点一下概率云就等于「观测」**：粒子收束、坍缩成一个确定的位置与一张票，并且这一次坍缩会**波及与它相邻的票**（旁边的云也跟着变清晰一点）。
目的地是一颗亮的锚点，永远不参与抖动。
这一个是把 #474 的哲学（诚实的未知 + 观测带来确定）做成可以玩的交互，不要求它比别的更实用，要求它**让人记住「不知道」是什么感觉**。

## 7. 交付契约（六个人完全一样）

1. **一个文件**：`<原型目录>/474-<你的编号>-<英文短名>.html`。单文件自包含：不许 `<script src>`、不许 `<link href>`、不许联网、不装任何包、不用定时器轮询。
2. **双击即开**：用 Chrome / Edge 打开就完整可用；所有数据内联在文件里。
3. **自适应**：宽度 400 与 810 都要能用（面板会被用户拖窄拖宽）；`?w=400` 与 `?w=810` 都要正确渲染。
4. **URL 参数**：至少支持 `?w=`（宽度）、`?s=active|empty|big`（状态）、`?bar=0`（隐藏底部控制条，用于截图）。
5. **键盘可达**：Tab 能走遍所有可交互元素，Enter/Space 等同于点击；`←` `→` 不被拦截（除非焦点在输入框）。
6. **诚实渲染**：数据缺字段时按空渲染，不许抛错；`tickets: []` 时给「这是一张空图」的状态，不是白屏。
7. **自检**：写完后用 node + playwright 跑一次自检（脚本可参考 `<原型目录>/../.tmp-474-live/shot10.cjs` 的写法），确认：
   - 页面加载无 JS 报错（`pageerror` / `console.error` 都为空）；
   - `?w=400` 与 `?w=810` 下 `document.body` 无横向滚动（`scrollWidth <= clientWidth + 2`）；
   - 四个状态的票**都出现在 DOM 里**（用你自己给的 class 名或 data 属性断言，例如 4 张票对应 4 个节点）。
8. **产出截图**：把 810 宽与 400 宽各截一张 PNG，放到 `<原型目录>/../474-shots/` 下，文件名 `<你的编号>-<短名>-810.png` / `-400.png`。

## 8. 不要做的事

- 不要改别人的文件、不要动 `src/` 与 `host.js`（那是插件本体，本次只做原型）。
- 不要 `git add` / `git commit`。
- 不要安装 npm 包（`playwright` 与 `node` 已装好，直接用）。
- 不要为了好看牺牲那五条语义（尤其：终点必须永远可见；雾不许伪装成待办；状态不许只靠颜色）。
