  • ✓
    ④ 弹窗/浮层不被裁剪（portal 挂顶）
    需 portalTop 挂 document.body · zIndex 2147483000 · RDOM 缺失退化 · 本原型 tooltip 已挂到 body，祖先 transform 不影响，可在审查元素中核验
  • ✓
    ⑤ 富文本/懒求值内容（后续不改接口）
    需 content 支持 string | VNode | ()=>VNode，content 优先于 children · 本原型以字符串演示，契约已预留形态，调用方传函数即可
结论（预填，待维护者拍板）： 5 项均可由同一 HoverTip 契约覆盖，无需第二套定位/翻转/挂顶分支。建议维持 G2 推荐打包不变，进入 T1/T2 直接落地。

HoverTip(props) // h 工厂，经 DswsCtx 取 h/timer/localeSvc，消费 kernel/portal.js 的 portalTop { content?: string | VNode | () => VNode, // 主入口，富内容不改接口 children?: string | VNode, // 别名，content != null 时忽略 mode?: 'anchor' | 'mouse', // 默认 'anchor'，首轮不做 'fixed' targetRef?: Ref, // mode=anchor 时锚点 offset?: { x: number, y: number }, // 默认 anchor {8,0} / mouse {14,12} maxWidth?: number, // 默认 220 flip?: boolean, // 默认 true（auto 按 window 视口，caret 随翻转自动上下/左右） delay?: { show: number, hide: number }, // 默认 {show:0, hide:160} visible?: boolean, // 受控优先，未传则非受控局部 state onVisibleChange?: (next: boolean) => void, onShow?: () => void, onHide?: () => void, zIndex?: number, // 默认 2147483000 }
状态：默认非受控局部 state，支持 visible 受控兜底；T2 一次性删除 s.skillTip/s.cfgTip/s.skillHover 等全局键，不留 shim。样式走 STYLE_TEXT，气泡 pointerEvents none。
