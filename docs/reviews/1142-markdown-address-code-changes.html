本地 Markdown 房的票，现在带上自己的文件地址

票的地址改成由真正读写那个文件的那一层填进票里：界面「打开票」有东西可开，工具回执里也有地址了。文件名里带标题转出来的后缀，所以地址只能是盘上那个真实文件的路径，不能按编号猜。

14 个文件 +84 −24 房间代码 6 个 回归测试 1 个 金标准回执 7 份 / 9 行 url

改动的形状

改前：地址在门口丢了

  1. 读／写票文件的那一层知道路径（01-hello-world.md）
  2. parseMd 写死 url: ''，路径没进门
  3. 票没有地址 → 界面渲染出 href=""，回执里 "url": ""
  4. 宿主那段「票的 url 为空就按后端现算」读的是投影之后的模块对象，投影按设计只带数据字段、函数被挡在门外 → typeof … === 'function' 恒为假，永远进不去

改后：谁读文件谁填地址

  1. 同一层读／写文件，顺手把路径交给 parseMd
  2. parseMd 收 url 入参（不传就是空串，纯文本解析不受影响）
  3. 票自带地址 → 界面 issueUrlFor 取到路径，openIssueUrl 走 wf.openPath 打开票文件
  4. 地址是盘上真实文件名，不是按编号猜出来的规范名
