# 插件浅色外观各页面效果方案（#1366）

## 一、要解决的是什么问题

插件深色外观是长期使用的满意基线，浅色外观从未正式适配。用户明确不满意两处：按钮焦点周围的焦点圈在浅色下不好看；技能列表那套像素风页面在浅色下缺了点味道。本方案只定“浅色下每个页面长什么样”，不改生产代码，落地另起票。

## 二、定版的三句话

1. **焦点环**：原样跟随 DSH 主题，不写死色值。浅色下主题主色是 `#4176E6`（白底对比 4.23:1、纸面底 3.91:1，都过 3:1 线），宽 2 像素往里画，保持不变。
2. **像素风**：用 **A 纸面便签**——和版本管理浅色同一张纸。纸面 `#f6f1e6`、卡片 `#fffdf8`、描边 `#3a2c14`、字沿用宿主变量、强调色改深绿 `#15803d`。
3. **铺开范围**：A 纸面语言只铺像素家族（技能列表与详情、票卡片、地图卡片），其余页面沿用宿主变量自动跟随，不手写色值；文字对比只修不达标的个例。

## 四、色值清单（A 纸面便签，只管像素家族）

- 纸面 `#f6f1e6`、纸面下沉 `#efe8d9`、卡片 `#fffdf8`、描边 `#3a2c14`、字 `#221d15`（生产代码里字走宿主变量，不写死）、次要字 `#6f6252`、强调深绿 `#15803d`、危险 `#b91c1c`、警告 `#b45309`、信息 `#1d4ed8`。
- 焦点环：跟随主题（浅色 `#4176E6`），宽 2 像素往里画。

## 五、真机验收清单

1. 切到浅色外观，按第三节表格从上到下每页点开看一遍：像素家族三页是 A 纸面味道，其余页面字都清楚、没有发白发虚。
2. 在浅色下用键盘走一遍焦点：每个按钮的焦点圈都是蓝色细圈，没有看不见的。
3. 跑一遍相关门禁（改动影响到的那几扇），全绿才算过。
4. 以上都过，方案才算落地；落地是另一张实施票的事，不在这张图里。
